# タスク完了時のチェックリスト

## 必須確認事項

### 1. ビルド確認
```bash
npm run build
```
エラーがないことを確認

### 2. テスト実行
```bash
npm test
```
すべてのテストがパスすることを確認

### 3. コードスタイル確認
- JSDocコメントが日本語か
- コード内コメントが日本語か
- 絵文字が含まれていないか

### 4. コミット前確認
- コミットメッセージが日本語か
- 署名（Generated with Claude Code）が含まれていないか
- 絵文字が含まれていないか

## コミット例
```bash
git add .
git commit -m "機能追加: 新しいMCPツールを実装"
```

## セキュリティ確認
- APIキーやシークレットがハードコードされていないか
- 入力値のバリデーションがあるか
